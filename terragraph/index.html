Terrain Graph Editor
Preview Area
Select a node to preview

Library: Drawflow v0.0.60

Theme: Purple with Green Selection

Instructions:

  • Click port once to start connection, click another to complete
  • Upload images via "Upload Image" button in nodes
  • Hover over ports to see their names
  • Green port groups = enabled, Red = disabled
  • Drag nodes to move them
  • Right-click node to delete it
  • Mouse wheel to zoom

Features:

  • Stacked port groups with tooltips
  • File upload with image preview
  • Click-to-connect port system
  • RGB and RGBA node types
  • Channel-based operations
